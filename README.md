# Data Analytics Learning Notes — Jupyter Notebook Collection

Kumpulan notebook praktik untuk mendokumentasikan pembelajaran **analisis data menggunakan Python** dalam format Jupyter Notebook.

## Isi repository

- `PerintahDataAnalisis_Day02.ipynb`: catatan dan praktik sesi analisis data hari kedua.
- `PerintahDataAnalisis_Day03.ipynb`: kelanjutan latihan analisis data hari ketiga.
- `LICENSE`: informasi lisensi repository.

## Tujuan dan hasil

Repository ini berperan sebagai **arsip latihan bertahap**, bukan produk data analytics lengkap dengan pipeline, dashboard, atau metrik produksi. Kode, penjelasan, serta keluaran eksperimen berada di notebook masing-masing.

Untuk studi kasus analitik yang lebih lengkap dan berorientasi hasil bisnis, lihat [Global Electronics Retailer Analysis](https://github.com/Darren0099/global-electronics-retailer-analysis) dan [Annyeongbap Sales Analysis](https://github.com/Darren0099/annyeongbap-sales-analysis).
